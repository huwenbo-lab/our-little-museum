## 2. 各展厅现在的设计

### 序厅（intro）
芍药拱门 + 标题 + 开场文字 + “我们相识的第 N 天”（来自 `since`）+「开启参观」。

### 中央大厅（foyer）
标题、导语、三张展厅卡片、底部“相识第 N 天 · 展览仍在更新”和署名。
卡片用**真实照片**（`roomCovers`，见内容指南）：时间长廊 = 一周年合照，足迹 = 北戴河沙滩上写的字，终厅 = 25 岁生日拍立得背面“永远爱你”的手写。没填 `roomCovers` 时退回原来的插画。

### 时间长廊（timeline）—— 主展厅
```
时间长廊
[篇章标签 × 4]                       ← 横向可滑，当前篇章居中
 ●───────●───────●───────●          ← 圆点和连线在上方
 日期      日期      日期      日期       ← 文字在线下方，不再被线划穿
 标题      标题      标题      标题
──────────────────────────────
 日期 / 标题 / 正文 / 原话引文 / 地点链接
 [上一段]                     [下一段]
 照片按原比例直接展开（聊天截图单列、拍立得正反面并排）
 [还有 N 张聊天记录 · 展开]          ← 一件展品超过 2 张聊天截图时
 [上一段] [下一段] [回到这段故事]
```
- **先读故事，再看照片**；照片不裁切，点开进灯箱可左右切换、放大细节。
- **聊天截图折叠**：每件展品默认只展开前 2 张聊天截图，其余收在「还有 N 张聊天记录」里。想指定展开哪几张，给那几张加 `key: true`。普通照片和拍立得不折叠。第一篇章默认展开的聊天截图从 35 张减到 21 张。
- 标题统一写成短句（“麦麦卡、蓝莓和稻香村”），不再用空格隔开的关键词。

### 足迹展厅（places）
```
┌──────── 星图 ────────┐   [北戴河][长沙][南昌]…  ← 地点条，按第一次去的先后
│   哈尔滨 ○       北 │   第 4 站 · 2024.09.26
│ 北京 ○   ● 北戴河×3 │   郑州
│   ○ 郑州×2          │   纪念日开始的地方 / 说明
│ 成都 ○   ○ 吴城      │   在这里发生过 · 2 段回忆（点击跳到那一天）
│   ○ 长沙   ○ 南昌×9  │   照片
│     ○ 华林           │
│     ○ 深圳           │
└──────────────────────┘
```
- **位置**：按每个地点的 `lat/lng` 投影出大致方位，再从中心向外做一次“开方拉伸”，让中部密集的城市散开、边远城市收回；太近的光点自动推开。界面写明“按大致方位摆放，不按比例”——这不是地图。
- **连线**：按“第一次在那里留下回忆”的先后连成一条星座线（北戴河 → 长沙 → 南昌 → 郑州 → 北京 → 哈尔滨 → 华林 → 成都 → 吴城 → 深圳）。选中一站时，它的来路和下一站两段加深。
- **地名**：默认写在光点右边；放不下或会压到别的光点时，自动改到左边或下方。
- 地点条和键盘左右键都按星座顺序切换；手机上点光点后详情自动滚进视野；电脑上星图固定在左侧，看照片时不会滚走。
- 没有 `lat/lng` 的地点（如公开示范内容）仍用 `x/y` 摆放。

### 终厅（letter）
点信封 → 封口掀开、信纸探出 → 展开全文；减弱动态效果时直接展开。离开终厅再回来会重新从信封开始。

## 3. 内容维护（详见 `docs/CONTENT_GUIDE.md`）
```
照片归档（2024/2025/2026 + 照片归档清单.csv）
   │ python3 tools/prepare_photos.py   压缩、删 EXIF/GPS，生成 private/photo-index.json
   ▼
private/content.js   真实内容（结构同 content.js；本地运行时优先读取）
   │ node tools/check_content.mjs      检查引用、图片路径、公开内容是否混入私密内容
   ▼
公开仓库只含代码 + 示范内容
```
`private/` 不在 Git 里，**改之前先复制一份备份**（如 `private/content.backup-日期.js`）。
