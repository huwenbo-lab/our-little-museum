# Our Little Museum · 芍药主题爱情博物馆

本仓库是爱情博物馆网站的唯一维护版本。当前为 **DEMO**，只含示范故事和原创 SVG 占位图；尚未上传私人照片或聊天记录。

## GitHub Pages 部署

仓库主页 → Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save。等待部署完成后访问 `https://huwenbo-lab.github.io/our-little-museum/`。

**隐私提醒：本仓库当前为 Public。** 请不要把私人照片、住址、敏感聊天或正式情书直接提交到公开仓库。GitHub Pages 页面本身也是公开可访问的；即使之后删除文件，Git 提交历史中仍可能保留这些内容。

## 维护方法

- `content.js`：改日期、事件、地点、文字、照片路径、最后的信；
- `assets/`：放网站使用的插画和以后允许公开的图片；
- `index.html`、`app.js`、三个 CSS 文件：页面结构、交互和视觉主题。

# Our Little Museum · 我们的爱情博物馆

这是一份已经搭建好的可交互网站初版，采用「奶油白 × 芍药粉 × 浅香槟金」的明亮艺术博物馆风格，**不是静态设计图**。入口、展厅选择、时间线、照片切换、回忆星图、打开信封，以及手机端的导航均已实现。

## 1. 立刻在电脑上预览

解压 `our-little-museum-peony.zip`，进入同名文件夹，双击 `index.html` 即可在浏览器中打开；也可以在命令行进入文件夹后运行 `python3 -m http.server 8000`，访问 http://localhost:8000/。

如果你暂时没有照片，可以先用内置的抽象插画参观整座博物馆。图文内容目前都是**可替换的演示占位**，不代表你的真实经历。

## 2. 换成你们的真实照片和故事

所有内容都在 `content.js`，可以使用 VS Code、记事本或任何文本编辑器修改。保存后重新打开网页即可看到变化，不需要安装编程环境。

1. **修改首页**：找到 `title`、`recipient`、`openingLine` 等字段，替换标题与开场文案。
2. **修改时间线**：在 `timeline` 数组中，每条记录对应一个事件，填写 `date`、`title`、`short`、`story`。可以增加/删除事件，建议先留 5–8 个。
3. **添加照片**：把 `jpg`、`png` 或 `webp` 文件复制到 `assets/`，然后在某条时间事件的 `photos` 数组中填入相对路径。例如：

```javascript
photos: ['assets/first-date-01.jpg', 'assets/first-date-02.jpg']
```

建议照片文件名使用简单的英文、数字和连字符。没有上传照片时会自动显示内置插画；同一事件上传多张照片后，可点击箭头切换。

4. **修改足迹**：在 `places` 中填入地点名称、回忆文字、照片路径。当前的地图是艺术化的**回忆星图，不是真实地理地图**；`x`、`y` 只是展厅光点的视觉坐标。真实地理地图可在你提供地点和经纬度之后另行扩展。
5. **写最后的信**：在 `letter.paragraphs` 中填入信件段落，修改 `salutation` 和 `signature`。**送出前务必替换示范信件**。
6. 所有文字和照片替换后，把 `demoMode: true` 改为 `demoMode: false`，右上角的 DEMO 标记就会隐藏。

可随时添加素材，原来的展厅结构不用修改。建议先只放最有代表性的 6–8 个时间节点、20–30 张照片、3 个地点，以及一封亲手写的信。

## 3. 免费上线：Netlify Drop

1. 进入 https://app.netlify.com/drop ，登录 Netlify。
2. **把整个网站文件夹**（不是单独的 `index.html`，也不是 ZIP 压缩包）拖入网页。文件夹顶层需要包含 `index.html`、`styles.css`、`light-theme.css`、`peony-theme.css`、`content.js`、`app.js` 和 `assets/`。
3. Netlify 发布后会提供一个公开的 `*.netlify.app` 地址。使用该网址访问、生成二维码即可。
4. 后续修改：重新上传整个文件夹，或通过 Netlify 的项目部署界面更新站点。请确保是更新原网站而不是每次新建。

**不需要购买域名、服务器、数据库，也不用安装 React。** 整个网站是静态文件，可在 Netlify、GitHub Pages、Cloudflare Pages 等静态托管平台运行。

## 4. 关于隐私

- **默认托管是公开的。** 知道网站链接的人可能访问到你的私人照片与文字；不可把「不容易猜的网址」当作真正的访问控制。
- 如果要放私密内容，请先确认你的部署平台是否支持服务端访问控制、身份认证或受保护页面。**不要依赖前端 JavaScript 写一个简单密码弹窗来保护隐私**，那样不能真正保护页面文件。
- 不建议将身份证、住址、敏感聊天记录、账户信息等上传到公开网站。
- 如果只想生日当天私下展示，也可以先不发布，直接在自己的笔记本上打开 `index.html` 给她看。

## 5. 重要说明

- 页面包含一段非常轻的原创合成氛围声，默认关闭；点击顶部「♫」按钮才会播放。没有内置任何商业歌曲。如果想放你们喜欢的歌，需要确认使用权后再添加对应音频。
- 谷歌字体在线可用时更接近视觉设计；离线或部分地区无法访问时会自动回退到本地字体，不影响操作。
- 插画为可自由替换的 SVG 占位视觉素材；你们的照片没有被臆造或写入网站。
- 建议使用 Chrome、Safari、Edge 的较新版本，支持手机及电脑。

网站文件说明：`index.html` 是结构，`styles.css` 是基础视觉，`light-theme.css` 是明亮主题，`peony-theme.css` 是芍药视觉主题，`app.js` 是交互，`content.js` 是未来每次需要更新的展览内容，`assets/` 放照片和示意插画。

## 6. 当前版本说明

已移除「私人珍藏」展厅，现为中央大厅、时间长廊、足迹展厅、终厅情书。芍药为原创矢量装饰，可替换为真实照片。加入真实照片时请修改 `content.js`，初版的文字均为示范内容。
